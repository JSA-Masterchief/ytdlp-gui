# yt-dlp GUI

A modern, cross-platform-ready desktop frontend for [yt-dlp](https://github.com/yt-dlp/yt-dlp), built with PySide6.

> **Status:** v0.1.0 — feature complete. See `docs/ROADMAP.md`.

## Building from source

```bash
git clone https://github.com/<you>/ytdlp-gui.git
cd ytdlp-gui
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
python src/app/main.py
```

## Running the tests

```bash
python -m pytest
```

## Building the Windows app

```powershell
.\build.ps1                                # tests, build, smoke test -> one .exe
.\build.ps1 -FFmpegDir C:\ffmpeg\bin       # also embed ffmpeg.exe + ffprobe.exe
.\build.ps1 -OneDir                        # folder build instead (starts faster)
```

The default build is a single self-contained file, `dist\ytdlp-gui.exe`
(no Python needed), copied to `release\ytdlp-gui-<version>-win64.exe`.
The PyInstaller configuration lives in `packaging\ytdlp-gui.spec`; the app
icon is generated by `packaging\make_icon.py`.

## Keeping yt-dlp up to date

The app uses yt-dlp's own Python library, and each build bundles the yt-dlp
version installed when it was built. Sites change often, so the app can also
update yt-dlp by itself:

- On startup it quietly checks PyPI and offers an update when one exists
  (turn this off in **Settings → yt-dlp**).
- **Settings → yt-dlp → Check for updates** does the same on demand.

Updates are the official wheel from PyPI, verified against PyPI's SHA-256,
unpacked to `%APPDATA%\ytdlp-gui\ytdlp-updates\`, and used from the next
start. A downloaded version is only used while it is newer than the bundled
one, and the app falls back to the bundled copy if it fails to load.
**Use built-in version** in Settings undoes an update.

When running from source, `pip install -U yt-dlp` works as usual.

## FFmpeg

Merging video+audio, audio extraction and subtitle/thumbnail embedding need
FFmpeg. The app finds it in this order:

1. The path set in **Settings → FFmpeg path**
2. `ffmpeg.exe` on your `PATH`
3. `ffmpeg.exe` placed next to `ytdlp-gui.exe`, or embedded with `-FFmpegDir`
